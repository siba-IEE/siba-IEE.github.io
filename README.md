# Portfolio de Siba Kalivogui

Portfolio personnel, bilingue (français / anglais).

**En ligne :** https://siba-iee.github.io/

## Développement

```bash
pnpm install
pnpm dev      # serveur local
pnpm build    # build de production
```

Site statique (Astro), déployé automatiquement sur GitHub Pages à chaque `push` sur `main`.
